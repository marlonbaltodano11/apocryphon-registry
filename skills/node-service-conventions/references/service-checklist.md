# Checklist de servicio Node

- [ ] ESM y versión de Node fijada.
- [ ] Config validada al inicio.
- [ ] Logs estructurados con IDs.
- [ ] SIGTERM con drenaje y cierre.
- [ ] Health y readiness.
- [ ] Timeouts y retries en clientes.
- [ ] Manejo global de errores.
- [ ] Tests y typecheck en CI.
- [ ] Sin secretos en logs.
