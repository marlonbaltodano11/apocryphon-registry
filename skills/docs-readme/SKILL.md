# READMEs útiles

## Objetivo

Que una persona pueda instalar, ejecutar y entender el proyecto en minutos.

## Protocolo

1. Escribe un párrafo que explique qué es y para quién.
2. Añade quickstart copiable con requisitos y comandos.
3. Documenta configuración y variables de entorno.
4. Incluye comandos de desarrollo, test y build.
5. Añade troubleshooting de los errores más comunes.
6. Enlaza documentación profunda en lugar de duplicarla.

## Reglas

- Los comandos deben funcionar en una copia limpia.
- No incluyas capturas desactualizadas.
- No asumas conocimiento interno.
- Mantén el README corto y enlaza el resto.

## Verificación

- Un clon limpio sigue el README sin pasos ocultos.
- Los comandos se ejecutaron.
- Los enlaces funcionan.
