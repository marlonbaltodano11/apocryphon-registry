# Checklist de sesiones

- [ ] Cookies con `httpOnly`, `Secure` y `SameSite` adecuado.
- [ ] Access token de vida corta (minutos).
- [ ] Refresh token rotativo y revocable.
- [ ] Logout invalida la sesión en el servidor.
- [ ] Autorización verificada por recurso.
- [ ] Rate limit en login y refresh.
- [ ] Errores genéricos: no revelan si el usuario existe.
- [ ] Auditoría de login, logout y cambios de permisos.
