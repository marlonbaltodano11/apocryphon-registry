# Checklist WCAG práctica

- [ ] HTML semántico (`button`, `a`, `nav`, `main`, `label`).
- [ ] Todos los controles tienen nombre accesible.
- [ ] Orden de foco lógico y visible.
- [ ] Modales atrapan el foco y lo devuelven al cerrar.
- [ ] Errores asociados al campo con `aria-describedby`.
- [ ] Contraste mínimo 4.5:1 en texto normal.
- [ ] Imágenes con `alt` útil o decorativo.
- [ ] No hay contenido que dependa solo del color.
- [ ] Animaciones respetan `prefers-reduced-motion`.
- [ ] Flujo crítico probado con teclado y lector de pantalla.
